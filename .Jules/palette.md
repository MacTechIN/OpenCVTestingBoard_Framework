## 2024-07-18 - Overlay Button Accessibility and Focus Rings
**Learning:** Absolute positioned overlay buttons inside `overflow-hidden` containers often clip standard focus rings, impairing keyboard navigation visibility. Icon-only buttons must have `aria-label` utilizing `t()` translations for screen readers.
**Action:** When creating absolute positioned buttons (e.g., over images) within `overflow-hidden` containers, use Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to prevent clipping. Always adapt the ring color to the action's intent (e.g., `focus-visible:ring-red-500` for destructive actions, `focus-visible:ring-blue-500` otherwise). Ensure icon-only buttons include an `aria-label` attribute (using `t()`) and the inner icon has `aria-hidden="true"`.
