## 2024-11-04 - Image Uploader Accessibility & Re-upload UX
**Learning:** Absolute positioned overlay buttons (like the "clear image" 'X' button over the preview image) within `overflow-hidden` containers can cause keyboard focus rings to be clipped, hiding the focus state from keyboard users. Additionally, clearing a custom UI image preview without resetting the underlying hidden `<input type="file">`'s value prevents users from immediately re-uploading the exact same file, as the browser's `onChange` event won't fire if the file path hasn't changed.
**Action:** When implementing absolute positioned overlay buttons, use `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2` (and an appropriate ring color, like `focus-visible:ring-red-500` for destructive actions) to ensure the focus ring is visible and not clipped. Always reset `e.target.value = ''` inside the `onChange` handler of hidden file inputs if the UI allows clearing and re-selecting the same file.
