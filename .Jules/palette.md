## 2026-08-06 - Focus Ring on Absolute Overlay Buttons in Overflow Containers
**Learning:** When adding focus rings (`focus-visible:ring-2`) to absolute positioned buttons that sit on top of images inside `overflow-hidden` containers, the focus ring gets clipped by the container if the button is positioned at the edge (like `top-2 right-2`). Combining `focus-visible:ring-offset-2` with an existing `shadow-lg` prevents this clipping visually or offsets it correctly in Next.js/Tailwind setups, keeping the focus indicator clear and accessible for keyboard users without altering layout.
**Action:** Use `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:ring-red-500 shadow-lg` for absolute-positioned destructive overlay buttons instead of generic outline.
