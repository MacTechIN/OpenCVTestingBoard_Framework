## 2024-05-18 - Ensure Icon-Only Buttons Are Screen Reader Accessible
**Learning:** Found an accessibility issue pattern specific to this app's components regarding icon-only buttons (e.g., the "Remove Image" button in the Image Uploader). Even if they contain `title` attributes, screen readers may not consistently read them, and the visible icon can confuse assistive tech if not explicitly hidden. Furthermore, they often lack proper `:focus-visible` styling for keyboard navigation, leaving keyboard users unaware of their focus state.
**Action:** Always add an explicit `aria-label` utilizing the `t()` translation function, `aria-hidden="true"` on the internal icon element, and Tailwind `:focus-visible` classes (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-red-400 focus-visible:ring-offset-2`) for keyboard focus navigation to icon-only buttons.
