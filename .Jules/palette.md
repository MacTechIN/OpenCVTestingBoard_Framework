## 2024-03-24 - Image Uploader Accessibility and Reusability
**Learning:** Absolute positioned overlay buttons (like the clear icon over images) clip the keyboard focus ring when placed near container edges. Additionally, custom file inputs using `<input type="file" className="hidden" />` retain their selected file value even after the UI state clears it, preventing users from re-uploading the exact same file.
**Action:** Always add `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to absolute positioned buttons to prevent focus clipping, adjusting the ring color to the action intent (e.g., `ring-red-500` for destructive). Always reset `e.target.value = ''` in the `onChange` handler of hidden file inputs to ensure re-uploading the same file works.
