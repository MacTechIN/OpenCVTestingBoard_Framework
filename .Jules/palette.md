## 2025-03-05 - Overlay Button Focus Ring and Reusable File Upload
**Learning:** Absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers can clip default focus rings, hindering keyboard navigation. Additionally, hidden `<input type="file">` components can silently break UX if users clear an image and immediately try to upload the exact same file, as the `onChange` event won't trigger unless the `value` is reset.
**Action:** When implementing overlay buttons, especially inside tight or clipping containers, add explicit focus ring classes combined with ring-offset (e.g. `focus-visible:ring-2 focus-visible:ring-offset-2`). Adapt the ring color to the action's intent (`ring-red-500` for destructive, `ring-blue-500` otherwise). For custom file upload UIs using hidden native inputs, always reset `e.target.value = ''` at the end of the `onChange` handler to ensure idempotency.
