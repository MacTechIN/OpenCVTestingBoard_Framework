## 2025-06-25 - ImageUploader Accessibility Enhancements
**Learning:** Hidden file inputs (`className="hidden"`) must explicitly have `tabIndex={-1}` and `aria-hidden="true"` so that screen readers and keyboard navigation completely skip them. Additionally, for absolute positioned overlay buttons (like a remove image `X` button over an image) within `overflow-hidden` containers, applying `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` along with `shadow-lg` ensures the focus ring is visible and doesn't get clipped by the container edge, adapting the ring color to the action's intent (e.g., red for destructive).
**Action:** When creating custom file uploaders using a hidden native `<input type="file">`, always add `tabIndex={-1}` and `aria-hidden="true"`. Use explicit focus-visible ring classes with offsets for overlay buttons inside hidden overflow containers to maintain keyboard accessibility visibility.
