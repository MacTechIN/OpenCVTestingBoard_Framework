## 2023-11-01 - [ImageUploader accessibility and UX]
**Learning:** For absolute positioned overlay buttons (like the remove image button) within `overflow-hidden` containers, standard focus rings might clip. Combining Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` with `shadow-lg` ensures the focus ring is visible. Adapting the ring color to the action's intent (e.g., `focus-visible:ring-red-500` for destructive actions) improves user feedback. Additionally, to allow users to re-upload the exact same file after clearing it via custom UI, the native hidden file input's value must be reset (`e.target.value = ''`) inside its `onChange` handler.
**Action:** When creating absolute positioned buttons over images or within clipped containers, always include `focus-visible:ring-offset-2` to prevent clipping and choose a ring color matching the button's intent. When creating custom file upload UIs, ensure the hidden file input's value is cleared on selection.
