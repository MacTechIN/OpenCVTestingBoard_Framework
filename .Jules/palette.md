## 2024-05-18 - File Input Reset and Overlay Button Accessibility
**Learning:** For custom file upload UIs, users expect to be able to clear an image and re-upload the exact same file immediately. However, if the underlying hidden `<input type="file">`'s value isn't reset, the browser's `onChange` event won't fire for the same file. Also, when placing absolutely positioned "remove" buttons over images in `overflow-hidden` containers, standard focus rings can be clipped, requiring `focus-visible:ring-offset-2`.
**Action:** When implementing custom clear actions for file inputs, always clear the native input's value inside its `onChange` handler or clear function (`e.target.value = ''`). For absolute overlay buttons, use `focus-visible:ring-offset-2` alongside standard ring styles to ensure keyboard focus visibility isn't lost to clipping. Ensure these hidden inputs also have `aria-hidden="true"` and `tabIndex={-1}`.
