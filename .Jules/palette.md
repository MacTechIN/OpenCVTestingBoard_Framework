## 2024-05-19 - ImageUploader File Re-upload Fix and Focus Styles
**Learning:** When users clear an uploaded file via a custom UI button, they cannot re-upload the exact same file unless the native hidden file input's value is cleared in the `onChange` event, because the browser doesn't register a "change" if the same file is selected again. Also, icon-only absolute-positioned buttons over images need an explicit `aria-label` using the `t()` translation function, `aria-hidden="true"` on the internal icon, and Tailwind `:focus-visible` classes to ensure keyboard accessibility and screen reader support. Adding `tabIndex={-1}` and `aria-hidden="true"` to hidden file inputs is a defensive accessibility practice.
**Action:** When creating custom file upload UIs with a clear functionality, ensure the native input's value is reset (`e.target.value = ''`) inside its `onChange` handler. Always add `aria-label`, `aria-hidden="true"` on the icon, and `focus-visible` styles to icon-only buttons.
