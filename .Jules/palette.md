## 2026-09-27 - [Accessibility: ImageUploader Hidden Input & Close Button]
**Learning:** For absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers, using Tailwind `focus-visible:ring-2 focus-visible:ring-offset-2` can result in the focus ring being visually clipped by the container bounds if standard outline styling is used. `shadow-lg` isn't clipped, so combining it prevents focus ring clipping.
**Action:** When styling overlay buttons in `overflow-hidden` contexts, use `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none`. Additionally, to allow users to re-upload the same file after clearing it in custom UI uploaders, explicitly reset the underlying hidden native file input value (`e.target.value = ''`) inside its `onChange` handler.
