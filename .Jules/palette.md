## 2026-07-29 - Accessible overlay buttons with Tailwind
**Learning:** For absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers, standard focus rings can get clipped by the container's bounds or lack sufficient contrast against the underlying dynamic content. Icon-only buttons in these contexts also frequently miss critical semantic labeling for screen readers.
**Action:** When implementing overlay buttons, always combine `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` with an appropriate ring color (e.g., `focus-visible:ring-red-500` for destructive actions) to ensure the focus ring remains visible and semantic. Include `shadow-lg` to help the button and its ring pop against varied backgrounds. Always add an explicit `aria-label` using the translation function `t()` and set `aria-hidden="true"` on the internal icon element.
