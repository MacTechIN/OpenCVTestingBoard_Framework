## 2026-09-13 - Enhance ImageUploader Accessibility and Interaction
**Learning:** Found that custom hidden file uploads using standard button triggers can suffer from two distinct UX issues: 1) the native file input might reject selecting the exact same file after clearing if its internal `value` is not explicitly reset, confusing users who want to re-upload; 2) icon-only "remove" buttons absolutely positioned over dynamic content (like images) can clip focus rings if the parent container uses `overflow-hidden`, making it better to apply the focus styling directly on the button with `focus-visible:ring-offset-2`.
**Action:** When creating custom file inputs, always reset `e.target.value = ''` in the `onChange` handler to allow consecutive same-file uploads. Add `tabIndex={-1}` and `aria-hidden="true"` to hidden inputs as defensive a11y practice. Use `focus-visible:ring-offset-2` along with semantic `aria-label` and `aria-hidden` on internal icons for custom button elements positioned over overlay boundaries.
