## 2024-03-24 - Accessibility and State in Image Uploader
**Learning:** Icon-only absolute positioned buttons (like the image clear 'X' button) over overflow-hidden containers can clip the default focus ring. Furthermore, resetting native hidden file inputs (`e.target.value = ''`) inside their `onChange` handler is crucial for allowing users to re-upload the exact same file immediately after clearing. Also, adding `tabIndex={-1}` and `aria-hidden="true"` to hidden file inputs is a harmless defensive practice even though `display: none` natively removes them from the accessibility tree.
**Action:** When styling absolute positioned interactive elements with focus states, use `focus-visible:ring-offset-2` alongside the ring to prevent clipping. Always reset `<input type="file" />` values in the change handler for custom upload flows.
