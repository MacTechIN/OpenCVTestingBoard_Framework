## 2024-05-24 - Absolute Positioned Overlay Buttons Accessibility
**Learning:** When using absolute positioned overlay buttons (e.g., a "remove" button over an image) within `overflow-hidden` containers, standard focus rings can get clipped or look awkward, leading to poor keyboard navigation accessibility.
**Action:** Always add Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to prevent the focus ring from clipping. Ensure to adapt the ring color to the action's intent (e.g., `focus-visible:ring-red-500` for destructive actions, `focus-visible:ring-blue-500` otherwise). Ensure icon-only buttons have an explicit `aria-label` utilizing the `t()` translation function and `aria-hidden="true"` on the internal icon element.
