## 2024-05-25 - Image Uploader Re-upload UX & Overlay Button Accessibility
**Learning:** Custom file upload UIs often hide the native `<input type="file">`. If a user uploads an image, removes it, and tries to re-upload the same image, the browser ignores it because the native input's internal value hasn't changed. Also, absolute-positioned icon-only overlay buttons (like a clear button) often suffer from focus ring clipping inside `overflow-hidden` containers and frequently miss screen reader announcements.
**Action:** Always reset the native hidden file input's value (`e.target.value = ''`) inside its `onChange` handler after processing the file. Apply `focus-visible:ring-2 focus-visible:ring-offset-2` to absolute-positioned interactive elements to prevent focus ring clipping, and use explicit `aria-label` alongside `aria-hidden="true"` on the internal icon.
