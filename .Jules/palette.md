## 2025-02-28 - Image Uploader Accessibility & UX
**Learning:** For custom file upload UIs where the native hidden file input triggers uploads via a wrapper button, failing to clear the native input's value (`e.target.value = ''`) inside the `onChange` handler will silently fail if the user removes an image and attempts to re-upload the exact same file. Additionally, defensive accessibility attributes (`tabIndex={-1}`, `aria-hidden="true"`) on hidden inputs are a good practice, and icon-only delete buttons over absolute positioned overlay elements need careful focus visible styling with `ring-offset` so keyboard outlines don't get clipped.
**Action:** Always clear input values immediately after reading a file selection if the UI allows clearing and re-uploading, and remember to configure focus states (`focus-visible:ring-offset-2`) for floating absolute-positioned buttons.
