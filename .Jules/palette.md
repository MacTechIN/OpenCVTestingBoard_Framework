## 2024-05-15 - [UX/A11y] Focus Styles & Re-upload Fixes
**Learning:** For absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers, standard focus rings can be clipped. To fix this, use `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to prevent clipping. Adapt ring color to action intent (e.g., `focus-visible:ring-red-500` for destructive actions). Additionally, when a custom UI handles file clearing while keeping the native hidden file input intact, the native input must have its value reset (`e.target.value = ""`) in the `onChange` handler, otherwise re-uploading the exact same file fails.
**Action:** When adding absolute positioned action buttons in `overflow-hidden` wrappers, explicitly define Tailwind `focus-visible` offset utilities and ensure custom file upload UIs actively reset their underlying native `<input type="file">` states when files are cleared.
