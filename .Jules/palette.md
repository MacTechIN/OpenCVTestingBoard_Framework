## 2026-09-30 - Accessible Overlay Actions and File Input Resetting
**Learning:** For absolute positioned overlay buttons (like a "Remove Image" close button over an image) within `overflow-hidden` containers, standard focus rings can be clipped or invisible. Additionally, when a custom UI wraps a hidden `<input type="file">`, clearing the selected image in the UI doesn't clear the underlying input's value, preventing the user from immediately re-uploading the exact same file.
**Action:** Use Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to prevent focus ring clipping on absolute elements. Adapt the ring color to the action's intent (e.g., `focus-visible:ring-red-500` for destructive actions). Ensure to reset the native hidden file input's value (e.g., `e.target.value = ''`) inside its `onChange` handler after processing the file.
