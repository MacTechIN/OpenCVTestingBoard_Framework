## 2024-05-18 - Absolute positioned overlay buttons focus clipping and native file input UI constraints
**Learning:** Absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers can clip standard focus rings. Additionally, when using custom UIs to trigger native hidden file inputs, users cannot re-upload the exact same file after clearing it unless the input value is manually reset.
**Action:** Use Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` (and adapt the ring color, e.g., `focus-visible:ring-red-500` for destructive actions) to prevent the focus ring from clipping on absolute positioned overlay buttons. Also, always reset the native hidden file input`s value (e.g., `e.target.value = ""`) inside its `onChange` handler to ensure users can re-upload the same file.
