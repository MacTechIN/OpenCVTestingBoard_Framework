## 2025-06-15 - Overlay Button Accessibility
**Learning:** Absolutely positioned icon-only buttons overlaying images often lack focus visibility and proper screen reader descriptions. When a user navigates via keyboard, standard focus outlines might get clipped or become invisible against the background image. Additionally, screen readers need explicitly translated descriptions (using the app's `t()` function) for the button, and the decorative icon inside should be hidden from them to avoid redundant or meaningless announcements.
**Action:** For absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers, always use Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to prevent the focus ring from clipping. Set `aria-label` using the translation function `t()` and add `aria-hidden="true"` to the internal icon element. Adapt the ring color to the action's intent (e.g., `focus-visible:ring-red-500` for destructive actions).
