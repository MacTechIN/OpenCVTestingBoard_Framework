## 2024-10-31 - Improved Image Removal Button Accessibility and UX
**Learning:** Icon-only overlay buttons inside `overflow-hidden` containers (like the image preview in `ImageUploader`) are prone to clipping their native focus rings. Additionally, clearing a file input and immediately trying to select the exact same file is a common frustration caused by the browser's native `<input type="file">` not firing `onChange` if the `value` hasn't changed.
**Action:** When adding focus states to overlay buttons, use `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2` (and match the ring color to intent, e.g., `ring-red-500` for delete). Always explicitly reset the `e.target.value = ''` inside the `onChange` handler of hidden file inputs after extracting the file to ensure the same file can be re-selected. Redundantly adding `tabIndex={-1}` and `aria-hidden="true"` to hidden file inputs is a good defensive accessibility practice.
