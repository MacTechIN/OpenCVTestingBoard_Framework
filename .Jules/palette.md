## 2025-02-14 - ImageUploader Re-upload & Overlay Focus Accessibility
**Learning:** For custom file uploaders where a user can clear an image and immediately upload the same file again, the native hidden `<input type="file">` needs its value reset (`e.target.value = ''`) in the `onChange` handler to allow the browser to detect it as a change. Additionally, for absolute positioned overlay buttons (like the "Remove Image" icon over the uploaded image preview), standard focus rings get clipped due to the parent container's `overflow-hidden`.
**Action:** Always reset the file input value after handling the file if re-uploading the same file is a valid user flow. For overlay buttons inside hidden overflow containers, combine Tailwind classes `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` with `shadow-lg` to prevent focus ring clipping and maintain visibility for keyboard users.
