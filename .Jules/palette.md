## 2024-11-03 - [ImageUploader] Improve accessibility and UX for file uploads
**Learning:** Absolute positioned overlay buttons (like the remove image button over the image preview) need specific focus ring styling (`focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none focus-visible:ring-red-500`) combined with `shadow-lg` to prevent the focus ring from clipping against the container edges. Additionally, to allow users to re-upload the exact same file after clearing it via a custom UI, the native hidden file input's value must be explicitly reset (e.g., `e.target.value = ''`) inside its `onChange` handler.
**Action:** When implementing custom file upload components, always ensure the underlying native file input's value is cleared after reading the file, and ensure overlay buttons have sufficient offset for their focus rings to be clearly visible without clipping.
