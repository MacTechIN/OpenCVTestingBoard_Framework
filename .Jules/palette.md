## 2024-05-18 - ImageUploader File Input UX and Accessible Remove Button
**Learning:** For custom file upload UIs, users often try to re-upload the same file after clearing it. Native `<input type="file">` ignores `onChange` events if the selected file path hasn't changed, causing the UI to break silently. Additionally, absolutely positioned icon-only overlay buttons (like "Remove Image") often lack keyboard focus indicators and screen reader announcements, making them completely inaccessible.
**Action:** Always reset the native hidden file input's value (`e.target.value = ''`) inside its `onChange` handler to allow re-uploading the exact same file. For icon-only overlay buttons, always include `aria-label`, `aria-hidden="true"` on the icon, and robust keyboard focus styles (e.g., `focus-visible:outline-none focus-visible:ring-2`).
