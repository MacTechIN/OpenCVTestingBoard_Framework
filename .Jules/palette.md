## 2024-05-24 - Accessible Icon-Only Buttons over Images
**Learning:** For absolute positioned overlay buttons (e.g., over images) within `overflow-hidden` containers, default focus rings might clip or be hard to see against arbitrary image backgrounds. Icon-only buttons must have an explicit `aria-label` and hide their internal icons (`aria-hidden="true"`) to provide proper screen reader context.
**Action:** Always add explicit `aria-label` (using translation function if available), `aria-hidden="true"` on the internal icon element, and Tailwind `:focus-visible` classes for keyboard focus navigation. Use classes like `focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:outline-none` combined with `shadow-lg` to prevent the focus ring from clipping and adapt the ring color to the action's intent.
